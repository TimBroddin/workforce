## Beads Issue Tracking

**IMPORTANT: Before starting ANY work, create beads issues with `br create` to track the task. Always check
`br list` and `br ready` first to see if there are existing issues to work on.**

- `br list` — list open issues
- `br ready` — show unblocked issues ready for work
- `br create "title" -p <priority>` — create an issue
- `br close <id>` — close a completed issue
- `br show <id>` — view issue details
